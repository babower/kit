# Changelog: kit-charts

## 0.1.0 (2026-11-13)

First release, from the ops dashboard (which had ported and extended the prayer-flags
admin page): column, line and horizontal-bar charts, tooltips, table views, theme toggle,
phone-width drawings, the validated palette and light/dark tokens. Legends can show line
markers. The theme preference key is configurable (`window.KIT_CHARTS.themeKey`).
